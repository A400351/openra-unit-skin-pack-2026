## FAQ

**Will this affect game performance?**  
Minimal — OpenRA's renderer is sprite-based and the 2× pack adds only about 3% overhead.

**Does it work with custom mods?**  
The pack replaces base-game sprites only. Mod-added units use their own graphics.
